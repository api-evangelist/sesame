# Sesame

> Sesame is a direct-to-consumer telehealth marketplace connecting patients with
> board-certified clinicians for affordable, transparent, cash-pay virtual and in-person
> care. Patients browse and book pay-per-visit appointments across urgent care, prescription
> refills, weight loss and GLP-1 treatment, mental health, women's health, dermatology and
> pediatrics, with no insurance required and up-front pricing.

## API status

Sesame publishes **no public developer API**. As of 2026-08-15 there is no developer portal,
no API reference, no OpenAPI or AsyncAPI document, no SDK, no webhook catalog and no MCP
server. Sesame operates a private GraphQL endpoint at `https://api.sesamecare.com/graphql`
that backs its own consumer web and mobile applications: an unauthenticated GET returns
HTTP 401, and an introspection POST is rejected by Apollo Server with
`GraphQL introspection is not allowed by Apollo Server`. That endpoint is application
infrastructure, not an offered product, and no schema is published anywhere.

Partnership enquiries are handled by email at partners@sesamecare.com rather than through a
developer program.

## Open source

Sesame maintains a verified GitHub organization and publishes 17 first-party Node/TypeScript
packages to npm under the `@sesamecare-oss` scope. None of them is a client library for a
Sesame API — they are general-purpose platform utilities.

- [GitHub organization](https://github.com/sesamecare): 23 public repositories
- [@sesamecare-oss/redlock](https://www.npmjs.com/package/@sesamecare-oss/redlock): Distributed Redis locks
